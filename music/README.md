# MP3 folder for JJ RNG (development)

For a globally installed or `npx` copy, JJ RNG creates the real music folder automatically at:

- macOS: `~/Library/Application Support/nikki-realms/music`
- Linux: `~/.local/share/nikki-realms/music`

Put only MP3s you own or are authorised to use there. Filenames must match the collection names, for example `garam-dan-madu.mp3`, `dola-dola.mp3`, and `dalinda.mp3`. The game looks up the file locally and never downloads music.
